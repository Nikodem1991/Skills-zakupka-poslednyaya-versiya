# Skills zakupka - последняя версия

Это отдельный репозиторий с последней проверенной версией навыка `zakupka-v2`. Навык помогает выбирать товары и строить выгодную закупку, но сам заказ не оформляет.

## Что делает навык

Навык работает в двух режимах:

1. Анализирует точный товар по ссылке, фотографии, EAN, артикулу или модели.
2. Подбирает товар под задачу пользователя, когда конкретная модель ещё не выбрана.

В обоих режимах он:

- сначала проверяет назначение, совместимость и реальную пригодность товара;
- для химии сравнивает назначение, активные вещества, концентрацию, способ применения, ограничения, этикетку, TDS и SDS;
- проверяет независимые тесты, тематические форумы и повторяющийся опыт реальных пользователей;
- не считает рейтинг продавца или среднюю оценку достаточным доказательством качества товара;
- сравнивает полную сумму `brutto` с VAT, доставкой и обязательными сборами;
- нормализует цену по полезной единице: штуке, литру, килограмму, рабочему раствору или операции;
- показывает самое дешёвое доказанно хорошее решение и, если оно найдено, конкретно лучший вариант не дороже чем на 20%;
- отдельно ищет разумную оптовую альтернативу от 2 до 50 конечных единиц включительно;
- не рекомендует товар, если критичная совместимость, безопасность или итоговая стоимость не подтверждены.

## Allegro Smart

Для предложений, явно обозначенных Allegro Smart, навык учитывает бесплатную доставку при заказе минимум на `49,90 zł` у одного продавца и при общем совместимом способе доставки Smart.

Для регулярно используемой химии и других запасаемых расходников навык рассчитывает минимальное целое количество одинаковых упаковок, которое достигает порога Smart. Например, при цене `20 zł` за упаковку он анализирует покупку `3 × 20 zł = 60 zł` с доставкой `0 zł`, если весь запас безопасно хранить и реально использовать. Доставка остаётся частью расчёта, а не главным критерием выбора.

Актуальные условия нужно сверять с [официальной справкой Allegro](https://allegro.pl/pomoc/aktualnosci/zmiany-w-allegro-smart-od-2-marca-darmowa-dostawa-przy-zakupach-od-49-90-zl-u-jednego-sprzedajacego-jn6Ww9nd1i7).

## Ограниченный опт

Навык дополнительно ищет `hurt`, `opakowanie zbiorcze`, `karton`, `multipak`, `pakiet`, `zestaw` и партии по 10, 20, 25 или 50 штук.

Жёсткий предел - не более 50 конечных используемых единиц во всей закупке. Считается содержимое коробок: `5 коробок × 10 швабр = 50 швабр` допустимо, а `6 × 10 = 60` - нет. Паллеты, контейнеры, IBC и предложения с неизвестным количеством исключаются.

Оптовый вариант показывается только при реальной экономии без потери качества, совместимости или безопасности. В расчёте раскрываются полный платёж, цена единицы, экономия, излишек, хранение и ожидаемая полезность запаса.

## Безопасность

Навык не придумывает разведение химии и не предлагает самодельные смеси. Он следует этикетке и документации производителя. В частности, запрещено рекомендовать смешивание хлорсодержащих средств с кислотами, уксусом, аммиаком или другими очистителями.

## Файлы

- `SKILL.md` - канонический файл навыка для установки.
- `skillzakupka-v2.md` - идентичная по содержанию копия с удобным именем.
- `README.md` - описание назначения и основных правил.

Оба файла навыка должны всегда оставаться побайтно идентичными.

## Установка

Для Codex скопируйте папку навыка в каталог пользовательских навыков так, чтобы итоговый путь выглядел как:

```text
~/.codex/skills/zakupka-v2/SKILL.md
```

Для другой системы, поддерживающей формат `SKILL.md`, поместите канонический файл в её каталог навыков согласно документации этой системы.

## Примеры запросов

```text
Примени $zakupka-v2 к товару на фотографии и найди самую выгодную закупку в Польше.
```

```text
Найди хорошую недорогую химию для этой задачи, проверь состав, отзывы, Allegro Smart и опт до 50 единиц.
```

```text
Нужны швабры для фирмы. Сравни обычную покупку, Smart и разумную оптовую партию.
```
